# Steal from Granny: Prop Hunt

**Play:** https://kam-karma.github.io/steal-from-granny/

A cozy 3D sneak-and-steal browser game. You are a little jelly thief in Granny's house at night: copy any object, swallow the loot, and freeze whenever someone looks. Granny, Grandpa and Pamuk the cat are watching.

- **Controls:** WASD to move. E: tap to copy an object, hold to swallow it. Shift: close your eyes. Q: spit something out. Touch controls on phones.
- **Content:** 6 nights, Easy, Medium and Hard difficulty, daily quests, upgrades, jelly skins, an album and loot collection. Turkish and English.

Built with three.js, TypeScript and Vite. Made for Poki (the Poki SDK is wired in; without it the game still runs).

```
npm install
npm run dev      # http://localhost:5184
npm test
npm run build    # dist/
```

Art: furniture from Kenney and KayKit (CC0); characters made with Tripo3D; interface art made with Nano Banana; Fredoka font (SIL Open Font License).
